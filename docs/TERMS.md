## 2. What Shulker is

Shulker is a personal music tool that lets you:

- Search for music via YouTube Music
- Stream audio from YouTube via yt-dlp
- Download audio for personal offline use
- Resolve Spotify links to find matching YouTube tracks
- Organise music into playlists on your own server

Shulker is a technical tool for personal use. It is not a music streaming service, it does not host any audio content, and it does not have a content library.
