How it works

Simple by design.

Shulker is a thin layer between you and yt-dlp. No databases, no accounts, no complexity.

1

Search or paste a link

Type a song name — ytmusicapi searches YouTube Music and returns tracks, albums, artists, and playlists in under a second. Or paste any Spotify, YouTube, SoundCloud, or Bandcamp URL and Shulker resolves it automatically.

2

Tap to stream

The frontend calls /api/stream/{id}/audio. The backend checks if the file is downloaded — if yes, serves it from disk instantly. If not, pipes yt-dlp stdout straight through the response. Audio starts in 1–3 seconds either way.

3

Download to keep

Submit a download job. yt-dlp fetches the best quality, ffmpeg converts to your chosen format (MP3/FLAC/Opus/M4A/WAV), and mutagen embeds full metadata, artwork, and synced lyrics into the file. Done.

4

Play forever offline

Downloaded tracks appear in Library immediately. Play them with zero network activity — the stream endpoint serves from disk with full HTTP range support for instant scrubbing.

Quick start

Up in five minutes.

Choose your environment — Termux on Android, your Mac, or Render. 

# Install dependencies in Termux
pkg install ffmpeg python nodejs git

# Clone and set up backend
git clone https://github.com/picklem0b/shulker.git
cd shulker/api
pip install -e . --break-system-packages
cp .env.example .env

# Start the API
uvicorn app.main:socket_app --host 0.0.0.0 --port 8000

# In a second Termux session — start the frontend
cd ../web
npm install
npm run dev

# Open http://localhost:3000 in your browser
# Requirements: Python 3.13+, Node 18+, ffmpeg
brew install ffmpeg node python@3.13   # macOS
apt install ffmpeg nodejs python3.13   # Debian/Ubuntu

git clone https://github.com/picklem0b/shulker.git
cd shulker

# Backend
cd api && pip install -e . && cp .env.example .env
uvicorn app.main:socket_app --host 0.0.0.0 --port 8000 --reload

# Frontend (new terminal)
cd web && npm install && npm run dev
# Fork the repo, then connect to Render
# render.yaml defines both services automatically

# API service env vars to set in Render dashboard:
SPOTIFY_CLIENT_ID     = your_id
SPOTIFY_CLIENT_SECRET = your_secret
MUSIC_DIR             = /tmp/shulker/music
DOWNLOADS_DIR         = /tmp/shulker/downloads

# Web service env vars:
VITE_API_URL = https://shulker-api-vnny.onrender.com

# Note: free tier sleeps after 15 min inactivity
# First request after sleep takes ~30 s to wake
